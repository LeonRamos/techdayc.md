01 / evento

¿Qué es Tec Tech Day?

Un día completo de talleres prácticos donde la academia ISC del TSJ Zapopan acerca a las y los estudiantes a las herramientas que se usan hoy en la industria del software.

→ 01

Práctica, no diapositivas

Tres talleres simultáneos en los laboratorios LIA, LTI y LIS. Llegas con tu equipo y sales con un proyecto funcionando.

→ 02

Tema actual del mercado

Desarrollo móvil en Android, IA aplicada al código con GitHub Copilot y Claude, y dominio de la terminal.

→ 03

Hecho por la academia

Organizado por el TSJ Zapopan y la academia ISC, con ponentes que ejercen en la industria.

02 / talleres

Talleres simultáneos

9:00 am – 12:00 pm · Edificio L, Laboratorios de Sistemas. Cada estudiante elige un taller al registrarse.

LAB / LIA 01

Tu primera app mobile

Taller práctico orientado a estudiantes que desean iniciar en el desarrollo de aplicaciones móviles. Se abordarán conceptos básicos de estructura, interfaz de usuario y ejecución de una app funcional en Android.

Sinuhe Jaime Valencia ponente
Requerimientos
  • Laptop con Windows, macOS o Linux
  • Android Studio instalado
  • JDK 11 o superior
  • Emulador configurado o dispositivo Android con depuración USB
LAB / LTI 02

GitHub Copilot & Claude: from the beginning to build a small service

Introducción al uso de herramientas de inteligencia artificial para el desarrollo de software. Los participantes aprenderán cómo GitHub Copilot y Claude pueden asistir en la generación de código y construcción de un pequeño servicio.

Orlando Cano ponente
Christian Gómez ponente
Requerimientos
  • Laptop con acceso a internet
  • Cuenta activa en GitHub
  • Visual Studio Code instalado
  • Extensión GitHub Copilot configurada
  • Navegador web actualizado
LAB / LIS 03

Introducción a la línea de comandos

Taller introductorio para el uso eficiente de la línea de comandos en distintos sistemas operativos. Se revisarán comandos esenciales para la navegación de directorios, manejo de archivos y tareas básicas de automatización.

Juan Carlos Sedano ponente
Daniel Delgado Vargas ponente
Requerimientos
  • Laptop con Windows, Linux o macOS
  • Terminal instalada (PowerShell, Bash o equivalente)
  • Conocimientos básicos de uso de computadora

04 / faq

Preguntas frecuentes

¿Quién puede asistir?

El evento está dirigido a estudiantes del área de Sistemas Computacionales del TSJ Zapopan.

¿Tiene costo?

No. El acceso es gratuito, sólo necesitas registrarte mediante el formulario oficial.

¿Puedo asistir a más de un taller?

Los talleres son simultáneos, por lo que deberás elegir uno al momento de tu registro.

¿Necesito traer mi propio equipo?

Sí. Cada taller indica sus requerimientos de software y hardware. Llega con tu laptop ya configurada para aprovechar al máximo la sesión.

¿Dónde se realiza?

En el Edificio “L”, Laboratorios de Sistemas (LIA, LTI y LIS), del TSJ Zapopan.
